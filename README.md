# Astrobase

Astrobase is a platform designed to help students explore opportunities, resources, universities and pathways related to astronomy, astrophysics, physics and space science.

## Features

- Student registration and authentication
- Role-based access for Students, Organisations and Admins
- Organisation profiles and dashboards
- Organisation verification
- Resource submission and management
- Opportunity management
- University information
- Admin content review and moderation
- Explore and search features

## Tech Stack

- Python
- Flask
- MySQL
- HTML
- CSS
- JavaScript

## Project Status

Astrobase V1 is currently being developed as a functional web platform.

The current version focuses on the core platform structure, authentication, organisation workflows and content management.

## Future Plans

Future versions may include:

- Student profiles and personalized features
- Improved search and discovery
- Saving and reporting features
- Community features
- AI-powered guidance
- More advanced exploration tools

## Development
